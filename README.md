# Deepam Crackers

Mobile-first Diwali catalog. Customers browse and send an order on WhatsApp. Admin manages the catalog, orders, and analytics.

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5174 and proxies `/api` to the API on port 5050.

For a deployed frontend, set `VITE_API_URL` to the API origin.
